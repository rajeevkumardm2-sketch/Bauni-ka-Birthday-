# Happy Birthday Nisha 💗

A mobile-friendly pink-and-gold birthday surprise website for GitHub Pages.

## Personalize the photos
Put your own JPG photos in the `photos` folder and keep these exact filenames:
- `nisha-1.jpg`
- `memory-2.jpg`
- `siblings-3.jpg`
- `memory-4.jpg`
- `memory-5.jpg`

You can use only 3 photos if you like; any missing photo shows a cute placeholder instead of a broken-image icon. Use photos you have permission to share. For faster loading, resize photos to around 1000 px on the longest side and compress them before uploading.

## Add music
Put a music file named `birthday.mp3` inside the `music` folder. Use a song or instrumental you have permission to use. If no file is present, the page still works; music just won't play.

## Publish with GitHub Pages
1. Sign in at https://github.com and create a **Public** repository, for example `nisha-birthday-surprise`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `photos` and `music` folders (including your photos/music).
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two, refresh the Pages section, and open the published URL shown there. It normally looks like `https://YOUR-USERNAME.github.io/nisha-birthday-surprise/`.
7. Open the URL on your phone and test the surprise, images, and music before sending it to Nisha.

## Notes
- The music button needs a real `music/birthday.mp3` file. Mobile browsers usually require a tap before playing audio.
- The Google Fonts import is optional; the website uses fallback fonts if they cannot load.
- If you publish using a repository name other than `nisha-birthday-surprise`, GitHub will show the matching URL in Settings → Pages.
